# StrumMeng

StrumMeng is a universal iPadOS and iOS app for practising guitar strumming timing. The iPad is the host for practice, audio, timing feedback, and records; a paired iPhone acts as the swipe-based strum controller.

See [CLAUDE.md](CLAUDE.md) for development rules and [Docs/ARCHITECTURE.md](Docs/ARCHITECTURE.md) for architecture and product decisions.
